什麼是完美長方體

想像一個長方形的盒子。它有三個邊（長、寬、高）、三個面各有一條對角線，還有一條從一角穿到對角的最長對角線（體對角線）。如果只要求三個面的對角線都是整數，這種盒子叫 Euler brick，多到數不完。但「完美長方體」要求連那條最長的體對角線也剛好是整數——這個額外條件，從來沒有人找得到一個例子，也從來沒有人證明它不可能。電腦窮舉到最小邊大約 3 兆都還沒找到。
形式化定義

完美長方體是一個邊為 $a,b,c$ 的長方體，滿足三個面對角線與體對角線同時為整數：

$$\sqrt{a^2+b^2},\ \sqrt{b^2+c^2},\ \sqrt{a^2+c^2},\ \sqrt{a^2+b^2+c^2}\ \in\ \mathbb{Z}.$$

只滿足前三個條件的稱為 Euler brick。再加上體對角線為整數，就是尚未有人滿足、也尚未有人證否的條件。Euler 於 1769 年提出此問題。

已驗證：窮舉搜尋顯示最小邊 $\lesssim 3\times10^{12}$ 內無完美長方體

圖一：長方體的七條長度

綠色 = 三個邊與三個面對角線（Euler brick 已能整數化）；紅色 = 體對角線（完美長方體要求的那條額外條件）。

共同主線：每個 fiber 一條橢圓曲線

六篇論文研究的是同一個東西。對每個合用的「斜率」參數 $q$，都對應到一條特定的曲線；曲線上「座標全是分數」的點（有理點）若存在，就有機會給出一個完美長方體。反過來說，要證明某一族盒子裡沒有完美長方體，只要證明對應曲線上找不到合用的分數點就好。把幾何問題翻譯成「曲線上有沒有好點」，是整套工作的共同起手式。
形式化：per-fiber 橢圓曲線與 recovery map

對每個 Pythagorean 有理數 $q$，配一條橢圓曲線

$$E_q:\quad y^2 = x(x+1)(x+q^2).$$

$q$-fiber 上的一個完美長方體會逼出 $E_q$ 上一個有理點，其 recovery-map 值是一個真正的、非退化的邊。封閉一個子家族，就是證明在那裡沒有這種非退化的有理點。退化點（對應邊長為 0 或重合）不算數。

已驗證：每篇論文附 PARI/GP 腳本檢查曲線方程與點的退化性

Saunderson 家族（Paper A）

十八世紀有一個叫 Saunderson 的經典公式，可以批量產生 Euler brick。一個自然的問題是：這個公式產出的盒子裡，會不會剛好有一個是完美長方體？答案是不會。把「體對角線也要是整數」的要求代進去之後，問題塌縮成一條很簡單的曲線，這條曲線上能用的好點只有四個，而且每一個都對應到退化的盒子（壓扁了、不是真的盒子）。所以 Saunderson 公式整族出局。
形式化定義與結論

由經典 Saunderson 參數化產生的 Euler brick 中，沒有任何一個是完美長方體。體對角線條件塌縮成一條 genus-1 曲線，其 Jacobian 是 rank-0 的橢圓曲線 Cremona 80a1。

$E_{\text{80a1}}$ 只有 4 個有理點，逐一檢查皆退化。此為無條件結果。

已驗證（PARI/GP）：80a1 之 rank = 0，4 個有理點全部退化

Case B at p=1，與 genus-5 曲線上的 rank 障礙（Paper B）

這裡看一條單參數的盒子帶（邊長隨一個參數變動）。把完美長方體的條件翻譯出來，會得到一個經典的整數方程（Pell 方程），它的解剛好是 Lucas 數列中「位置為奇數」的那些項。而 1964 年 Cohn 的一個定理告訴我們：這串數裡能當完全平方的，只有最前面兩個。把這兩個代回去，盒子都是退化的。所以這條帶裡也沒有完美長方體。值得一提的是：有一個常用的「夾擠」工具（Chabauty）在這裡剛好用不上，因為它需要某個數比另一個小，但這裡兩者相等——這恰好印證了 Peschmann 提過的疑慮。
形式化：Pell → Lucas → Cohn

邊為 $(4q,\ q^2-4,\ 2(q^2-1))$ 的單參數 stratum 中無完美長方體。體對角線條件化為 Pell 方程

$$g^2 - 5q^4 = 20,$$

其解為 odd-indexed Lucas numbers；Cohn (1964) 的定理迫使 $q\in\{1,2\}$（皆退化）。此為無條件結果。

已驗證（PARI/GP）：Pell 解對應 $L_1=1,\ L_3=4$，唯二平方項
為什麼 Chabauty–Coleman 用不上

相應的 genus-5 曲線其 Mordell–Weil rank 等於它的 genus（皆為 5）。Chabauty–Coleman 方法需要 $\text{rank} < \text{genus}$，因此無法封閉這條曲線——確認 Peschmann 所提的疑慮。本文改以 Pell/Lucas/Cohn 的初等路線達成封閉。

其 Jacobian 的 ℚ-isogeny 分解中，genus-2 商的 $\text{Jac}(C_q)$ 同 isogeny 於 600a2 × 400a2——這兩條是 rank-0 曲線 120a2、80a1 的 $\mathbb{Q}(\sqrt5)$-rank-1 quadratic twist。正是這個「twist 把 rank 從 0 抬到 1」使五個 elliptic factor 全為 rank 1，導致 rank $\text{Jac}(C)(\mathbb{Q})=5=\text{genus}$。

已驗證（PARI/GP）：genus-5 曲線 Jacobian rank = 5 = genus；600a2/400a2 為 rank-1 twist

圖二：Lucas 數列中唯二的完全平方

Pell 方程的解對應 odd-indexed Lucas 數；只有 $L_1=1$ 與 $L_3=4$ 是完全平方（紅色標記），其餘皆非——Cohn 1964 定理的結論。

rank-positive fibers 與 Peschmann (5,2) 的解決（Paper C）

前面的曲線「好點很少」所以容易窮盡。但有些 fiber 的曲線「好點有無窮多個」（rank 為正），這種就難搞。Peschmann 留下最小的一個未解 fiber，記作 (5,2)。本文在一個明確的搜尋範圍內解決了它，外加另外六個正 rank 的 fiber，並且精確指出：為什麼那種想靠「新質因數一定會出現」的封閉手法在一般情況會卡住——關鍵在於它要追蹤的數列，跟有效定理能控制的數列其實不是同一個。
形式化定義與結論

在明確的搜尋窗格上，解決 Peschmann 最小的開放 fiber $(5,2)$，連同另外六個 rank-positive fiber。

並指出 natural「primitive-divisor」封閉在一般情形失效的確切原因：障礙住在與有效定理所界定者不同的數列中，且 primitive divisor 未必以奇 multiplicity 出現。

已驗證（PARI/GP）：fiber $(5,2)$ 及六個 rank-positive fiber 於搜尋窗格內無非退化有理點

Szpiro ratio 與例外軌跡的 ℤ[√2] 位置（Paper D）

每條橢圓曲線都有兩個數值指標，它們的比值（Szpiro ratio）大致反映曲線「有多病態」。本文把整個 $E_q$ 家族的這些量算得乾乾淨淨，並證明：對幾乎所有參數，這個比值不超過 4 多一點點；少數比值很大的例外，全都落在一條特定的 Pell 圓錐曲線上（座標在 ℤ[√2] 裡）。換句話說，這個家族整體是「乖」的，壞點稀少且位置可被精確描述。
形式化定義與結論

精確計算 $E_q$ 家族的算術：minimal model、conductor、discriminant，並界定其 Szpiro ratio：對幾乎所有參數至多 $4+\varepsilon$，large-ratio 例外落在 $\mathbb{Z}[\sqrt2]$ 的 Pell 圓錐上。density-one 上界為無條件。

實測最大比值 $\sigma_{\max}=4.6140$，出現於 $(256,121)$。

已驗證（PARI/GP）：$\sigma_{\max}=4.6140$ at $(256,121)$；density-one $\sigma\le 4+\varepsilon$

圖三：Szpiro ratio 的散佈與密度一上界

大多數 fiber 的 $\sigma$ 落在 $\le 4$ 的密度一帶（綠色虛線）內；最大者 $\sigma_{\max}=4.6140$ 出現於參數 $(256,121)$（紅色標記）。

Sophie–Germain 子家族：單曲線封閉所有質數（Paper E）

這一族盒子由質數 $p$ 來索引，有無限多個。要逐一檢查無限多個質數是不可能的。本文的漂亮之處在於：把對所有質數的條件，全部化約到單獨一條曲線上的好點問題；而這條曲線的好點是有限且能列完的，於是一口氣處理掉整條無限的質數尾巴，遠超任何有限掃描能做到的。最接近成功的差一點點是 (11,71)——它滿足體對角線和兩個面，可惜第三個面不行。
形式化定義與結論

對每個質數 $p$，Sophie–Germain 兩個分支皆不產生完美長方體。單一一條橢圓曲線 Cremona 800a3 處理掉整條無限的質數尾巴，超出任何有限掃描。對質數 $p$ 為無條件結果。

唯一的 near-miss $(11,71)$ 滿足體對角線與兩個面，但第三個面不成立。

已驗證（PARI/GP）：800a3 之有理點有限且可窮盡；near-miss $(11,71)$ 第三面失敗

Mordell–Weil rank 與實驗調查（Paper H）

最後一篇是實驗性的普查。它對 303 個 fiber 的曲線量了「好點有幾個獨立方向」（rank），畫成直方圖：大多數是 0 或 1，少數到 2，只有三個到 3。其中一個被嚴格認證為 rank 3 的，是 pair (22,17)。它還留下一筆可重複驗證的紀錄：所有邊長 ≤ 30000 的 36 個 primitive Euler brick 裡，沒有任何一個是完美長方體。這些數字本身不解決問題，但替後續研究畫出了地形圖。
形式化定義與結論

給出一個經認證的 fiber，pair $(22,17)$，其 $E_q$ 在 $\mathbb{Q}$ 上 Mordell–Weil rank = 3；303 個 fiber 的 rank 直方圖為 rank 0：118、rank 1：137、rank 2：45、rank 3：3。

並驗證紀錄：所有邊 $\le 30000$ 的 36 個 primitive Euler brick 中，零個完美長方體。

已驗證（PARI/GP）：$(22,17)$ 之 $\mathbb{Q}$-rank = 3；303 fiber 分布 118/137/45/3

rank 0：118 個、rank 1：137 個、rank 2：45 個、rank 3：3 個。其中 $(22,17)$ 為經認證的 $\mathbb{Q}$-rank 3 fiber。

誠實的範圍說明

把話講清楚：這六篇是六個乾淨的部分結果與結構地圖，不是問題的解答。完整的完美長方體軌跡是一個非常複雜的曲面（general type），它「分數點到底有沒有有限多個」是由兩個目前同樣沒人會證的大猜想（Bombieri–Lang 與 Vojta）支配的，遠超現有方法可及。本站的貢獻是：無條件封閉幾個有名字的子家族、解決幾個特定的開放案例，並精確標出初等與曲線方法在哪裡停下來。它與近期 Peschmann、Yoshida、Naskręcki 的工作互補。
形式化：為何整體問題仍開放

完整的完美長方體軌跡是一個 general type 曲面，其有理點有限性受 Bombieri–Lang 與 Vojta 猜想（皆開放）支配，目前遠超出可及範圍。

本站的貢獻定位為：無條件封閉具名子家族、解決特定開放 fiber、並精確標出初等與曲線理論方法停滯之處。與 Peschmann (2026)、Yoshida (2024)、Naskręcki (2013) 互補。完整 LaTeX 原始碼、submission index 與 PARI/GP 驗證腳本皆隨各論文附於 repository。
